# Scientific Calculator (Web)

A browser-based scientific calculator with a retro calculator-style interface. Built entirely with HTML, CSS, and JavaScript — no installation or backend required.

## Features
- Basic operations: Addition, Subtraction, Multiplication, Division
- Advanced operations: Square root (√), Power (xʸ), Percentage (%), Factorial (x!)
- Trigonometric functions: sin, cos, tan
- Inverse trigonometric functions: sin⁻¹, cos⁻¹, tan⁻¹
- Logarithmic functions: log (base 10), ln (natural log)
- Constants: π (pi), e (Euler's number)
- Degree / Radian toggle for angle calculations
- Parentheses support for complex expressions
- Clear (C) and Backspace (⌫) functionality
- Live preview of result as you type
- Full keyboard support (numbers, operators, Enter, Backspace, Escape)
- Responsive design — works on desktop and mobile

## Tech Stack
- HTML
- CSS
- JavaScript (vanilla, no frameworks or libraries)

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Start calculating!

## Deployment
This is a fully static project, so it can be deployed on any static hosting platform:
- **GitHub Pages** — push to a repo and enable Pages from Settings
- **Netlify** — drag and drop the folder, or connect the repo
- **Vercel** — import the repo and deploy

No build step or backend is needed — `index.html` is the entry point.
